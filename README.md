Responsive Landing Page

About the Project
This project is a responsive landing page created using HTML and CSS. It is designed to promote a sample product or service with a clean and attractive layout.

Features
- Responsive design for mobile and desktop
- Header and navigation section
- Hero section with a heading and button
- Features section
- Footer section
- Clean and user-friendly design

Technologies Used
- HTML5
- CSS3
- CSS Flexbox and Grid

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the "index.html" file in your web browser.

Project Structure
- "index.html" – Contains the webpage structure.
- "style.css" – Contains the styling and responsive layout.

Objective

The objective of this project is to learn how to create a responsive and user-friendly landing page using HTML and CSS.
